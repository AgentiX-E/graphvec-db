## 是否需要优化的判定

**已完成 = 竞品中已无差距的：**
- **WAL 可靠性**：Segment Log + 固定 64MB segment + prune 只 unlink → ✅ 达到 LMDB 级别
- **批量发送**：EventBus.batchSend() → Raft 复制吞吐 → ✅ 超过逐条发送
- **PerPeer 隔离**：故障不会扩散 → ✅ 超过单 worker 架构
- **心跳检测**：可探测离线分片 → ✅ 赶上 Dgraph/Neo4j
- **乐观锁**：写冲突检测 → ✅ 基础事务能力
- **Cypher-lite 查询**：本地解析 → ✅ 超越 Zero 查询语言
- **Outbox 二级索引**：LMDB 前缀扫描瓶颈消除 → ✅ 应对大 outbox

**未完成但竞品差距最大的（优先级排序）：**
1. **MiniSearch 全文索引**（S03）— 竞品 Lucene/Bleve/IResearch 均有
2. **Schema 系统**（S02）— 竞品均支持
3. **REST API 补齐**（Q04）— 可用性和集成
4. **Rebalancer 一致性校验**（SH03）— 分布式正确性
5. **mTLS 认证**（E01/E04）— 安全差距
