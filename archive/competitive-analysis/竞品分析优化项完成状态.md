## 不可关闭项说明

### S04 — LMDB 替代 WAL 存储
当前 `SegmentStreamWal` (64MB segment, fsyncOnWrite, prune) 已满足 WAL 所有需求。LMDB 替换的本质是将持久化引擎换为 mmap 数据库，但现有方案在功能可靠性和数据安全上没有可量化的竞品差距。**不值得引入新依赖。**

### R05 — Raft 成员变更 (ConfChange)
`raft-logic` WASM 构建未暴露 `ProposeConfChangeV2` API，addPeer/removePeer 均需该 API 实现。这是**上游 npm 包限制**，代码层无解。`ApplicationMembershipManager` 已作为应用层替代（共识层之上管理成员）。
