```

新: AuthConfig { mode: 'mtls' }  // 唯一模式
    IdentitiesFile.json { map<CN, AuthorizedIdentity> }  // chokidar 热加载
    AuthResult { databases: string[] }  // 数据库级 scope

                         ^^^^
                         ↓
DatabaseManager.resolve('mydb')
  → GraphEngine { nodes.dat, edges.dat, adj_*.dat } 在 mydb/ 下
  → ShardManager (Raft 分片实例)
    → RangeInstance (每个 shard 一个 Raft group)
```

### 3. EventStream 跨节点架构

```
进程 A                            进程 B
  │                                 │
  ├─ EventStream.emit(msg)         │
  │   ├─ wal.append()             │
  │   ├─ bus.emit() через PUB     │
  │   ├─ pendingTracker.set()     │
  │   └─ retry loop (3s)          │
  │               │              │
  │         ZMQ PUB ─────────────│─→ SUB 收到
  │               │              │   ├─ dedup (msgId)
  │               │              │   ├─ bus.emit('event:ack')
  │               │              │   ├─ wal.markConsumed()
  │               │              │   └─ _emitLocal(callback)
  │               │              │
  │        ← ACK via ZMQ ────────│─→ pendingTracker.delete(msgId)
  │                                 │
  ├─ CURVE 密钥: PUB serverKey    │
  └─ CURVE 密钥: SUB serverPublic │--> CURVE 密钥: PUB serverKey
                                  │.. CURVE 密钥: SUB serverPublic 等
```

### 4. 存储架构

```
旧 WAL: wal.ts
  - fs.writeSync() — 无 fsync
  - entries: WalEntry[] — 全内存
  - truncateBefore() — 全量重写
  三处 P0 缺陷

新 WAL: lmdb
  - lmdb.transactionSync() — 自动 fsync
  - 数据在 mmap — 零拷贝，不常驻内存
  - truncate — 删 db 记录，不重写文件
  - 崩溃恢复 — LMDB 原生保证
```

### 5. 图算法架构

```
旧: src/core/graph-algorithms.ts
    astar.ts, dijkstra.ts, scc.ts, 连通分量,
    BFS, DFS, metrics.ts, 社区发现 — 8 文件自研

新: graph-adapter.ts (~60 行)
    OverGraph → graphology Graph (内存)
    graphology.* 调用成熟实现
    覆盖 50+ 算法
```
