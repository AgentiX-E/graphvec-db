## 关键技术点（新增记忆）

### `_walkMultiSteps` range BFS 分支新实现（query-parser.ts）
- 用 `newPaths` 累积，遍历每条前序 path `p`（`sidx=p[last]`），BFS 记录 `ends=[{end, hopsAt}]`。
- `minHops===0` 时 push `{end:sidx, hopsAt:0}`（零跳 self-match）。
- BFS depth 1..maxHops，`depth>=minHops` 且 `_stepMatchConstraint` 通过才 push end。
- 零跳（hopsAt===0）产物是 `[...p]`（前缀不变），非零跳是 `[...p, end]`。
- 边标签检查：`hasEdgeLabel` 时 `e.label !== step.edgeLabel` 则 `nextFrontier.add` + continue（不再加 end，但允许继续遍历）。

### cross-join 节点变量绑定（query-executor.ts `_executeMultiMatchCrossJoin`）
- 节点变量绑定为**节点索引（number）**，join 时 shared var 数值相等才保留。
- 单步分支：`if (edgeVar) m[edgeVar]=rel` + src/tgt 绑定 `m[srcVar]=s/d`。
- 多步分支：`firstSt.source → path[0]`，`lastSt.targetAlias → path[length-1]`。
- 最后把节点索引还原为对象：`row[k] = allNodes[v]`（v 是整数且 in range）。
- rel type 过滤读 `_type`/`__edgeLabel`（原来读不存在的 `rel.label`）。
