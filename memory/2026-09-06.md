### Commit `473f82bf` — collect(row) 对 MATCH 变量未摊平
**根因**：`_preProcessAggregateWith` 用标量 `collect()`（expression-engine.ts:1489，把参数包成单元素数组 `[v]`）求值 `collect(row) AS rows`。当 `row` 是 MATCH 变量、varCtx 里已持有完整匹配数组时，产生嵌套数组 `[[...]]`，导致 `UNWIND rows AS node RETURN node.id` 把整个数组当单元素展开 → `node.id` 对数组求值崩溃。
