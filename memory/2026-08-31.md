### 关键架构决策
- **删 `planForGe.aggregate` 当有 optionalMatchSteps**：GE 不知道 OPTIONAL MATCH 变量（x/f/n 不可见），让它聚合会拿到错误的 n.props 值。删掉后 QE 的 post-aggregation 路径在 OPTIONAL MATCH 展开后的 result 上折叠。
- **`plan.aggregates[]` 向后兼容**：单聚合时与 `aggregate` 等价；多聚合时 `aggregate` 指向第一个，`aggregates` 含全部。
- **percentile 不被 `extractReturn` 识别为聚合**（正则保持 `count|sum|avg|max|min|collect`，不含 percentile），否则 `percentileDisc(0.90, deg)` 这类「WITH 变量 value」场景走 GE `_execAggregation` 拿到 `n.props['0.90']`=undefined → nums 空提前 return 0，掩盖 NumberOutOfRange 抛错。已确认此改动后 Aggregation6 恢复 13/13。
