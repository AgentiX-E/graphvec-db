### 决策

- [5] 是 harness 架构 gap（缺 WITH 跨语句变量绑定 + 嵌套 UNWIND CREATE 边创建），需单独处理，不阻塞 percentile 交付

### 关键教训
- `unwind.list=[]` 是正常的（range/表达式 UNWIND 的 list 惰性求值，`var` 保存表达式文本）

- `having executed` 多语句 merge 逻辑正确合并 `UNWIND ... + CREATE`，但展开后 alias 去重会吞掉多节点（需唯一 alias 后缀）
