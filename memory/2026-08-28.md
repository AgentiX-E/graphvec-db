## Aggregation6 [5] percentileDisc 复杂查询修复 — 完成 ✅

承接 2026-08-27 的 percentile 工作，本日完成最后一个缺口 [5]。

### 根因链（三层，均已修复）

**[5] 查询**：
```
MATCH (n:S)
WITH n, size([(n)-->() | 1]) AS deg
WHERE deg > 2
WITH deg
LIMIT 100
RETURN percentileDisc(0.90, deg), deg
```
期望：deg 是出度数（3..11 均 >1），作为 percentile 参数应抛 `ArgumentError: NumberOutOfRange`。

三层根因：

1. **harness 跨语句变量绑定缺失**（`step-definitions.ts` `having executed` 多语句分支）
   - `UNWIND range(0,10) AS i CREATE (s:S) WITH s, i UNWIND range(0,i) AS j CREATE (s)-[:REL]->()` 中，`WITH s, i` 不产生可传播变量 → `range(0,i)` 的 `i` 无值 → `_resolveUnwindList` 抛 `ArgumentError` → 被 catch 吞掉 → 整条语句跳过 → 边未创建。
   - **修复**：引入 `varEnv: Map<string, unknown[]>`（行对齐变量环境），记录 UNWIND 变量和 CREATE 节点变量；对「source 是多节点变量 + UNWIND var 引用 varEnv」的边创建做**行级展开**（每个 s_k 创建 i_k+1 条边）。

2. **parser 的 UNWIND name bug**（次要，不影响本次）：`UNWIND range(0,i) AS j` 的 `name` 被解析成 `"i"`（提取了 range 第一个参数）而非 `"j"`。未修（不影响 [5]，因关键不是 j 的名字）。

3. **pattern comprehension `[(n)-->() | 1]` 求值丢失 `__edges`**（`query-executor.ts`）
   - GE 结果行的节点对象只带 `_label`/`_alias`，丢 `__edges` → pattern comprehension 拿到空 edges → `size` 返回 0。
   - `MATCH (n:S) RETURN size([(n)-->() | 1])` 走 GE 路径正确（List6 通过），但 `WITH n, size(...)` 走 WITH 表达式求值路径（`_evalBinary`）丢 `__edges`。
   - **修复**：在 `query-executor.ts` WITH 表达式求值的 `rc` 构造后，对节点变量按 `_alias` 从 `allNodes` 回填 `__edges`（约 line 3074-3090）。

### 附带修复

- **expression-engine.ts `_computeAggregate` 空集语义**：percentile 空集/全 null 现在返回 `null`（原返回 `0`，错误）。改动 `if (!values.length) return (fn === 'AVG' || fn === 'PERCENTILEDISC' || fn === 'PERCENTILECONT') ? null : 0`（对标 AVG 的「无有效数值」语义）。

## 2026-08-28 晚上 — UNWIND name 解析修复（commit 71309823）

### 完成
- **parser bug**：`UNWIND range(0, i) AS j` 的 `unwind.name` 误解析为 `"i"`（应为 `"j"`）。
- 根因：`extractUnwind`（ast-to-plan-v2.ts ~2042）用 `findChild(unwindCtx, 'VariableContext')` 取第一个 VariableContext；当列表表达式引用变量（`range(0,i)` 的 `i`）时，第一个是 `i` 而非 AS 后的 `j`。诊断确认 UnwindClauseContext 里 VariableContexts = `["i","j"]`（range 参数在前、AS 目标在后）。
- 修复：改取 `findAllChildren(unwindCtx, 'VariableContext')` 的**最后一个**（AS <var> 永远是 UNWIND 子句里最后变量）。
- 提交：`71309823`（Lambertyan 署名，全英文），2 files +44/-2（ast-to-plan-v2.ts + unwind.spec.ts）。
