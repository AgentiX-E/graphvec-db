### 修复内容（提交 976010d7）

**1. `_fixScanLabel` regex 修复** — `:A` 在 `:A:B` 中不被识别为 label（lookahead 只接受 `)` / 空格 / 行尾，不接受 `:`）。修复：lookahead 加上 `:`。

**2. 多标签检测修复** — 当 `_fixScanLabel` 清空了 `scanLabel`，多标签检测代码不运行。新增 fallback 路径：从 query 文本推测多标签并恢复 scanLabel + labelExpr。

**3. 提取 MATCH 变量的 regex** — `/(\w+)\s*(?::|\))/g` 不匹配内联属性模式 `(n {...})`。修复：在 lookahead 中增加了 `{`。

**4. 笛卡尔积支持 `MATCH (n), (m)`** — 单变量无边 MATCH 处重构为多变量通用版本，支持 `>= 2` 变量通过递归生成笛卡尔积。

**5. scanLabel 过滤 edge walk** — `_walkMultiSteps` 遍历时从所有节点索引 0 开始，不按标签过滤。新增 `plan.scanLabel` 过滤起始节点。

**6. 自环遍历修复** — 移除 `neighborIdx !== fidx` 限制（阻止自环匹配），移除 undirected fallback 中的自环排除。

**7. OR 类型边标签支持** — `edgeLabel` 按 `|` 分割检查（`:KNOWS|HATES`）。
