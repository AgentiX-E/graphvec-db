### 修复内容详解

**1. null 算术传播** — `_evalAddSub`, `_evalMulDiv`, `_evalExp`, `_evalUnary` 中，任一操作为 null/undefined 时返回 null（而非 NaN）。Cypher 语义：null 参与算术 ⇒ null。

**2. UndefinedVariable 编译时验证** — `MATCH () RETURN foo` 现在正确抛出 `SyntaxError: UndefinedVariable`。修复了 edge 变量 `[r]` 的提取 regex（`(?::|\))` → `(?::|\]|\))`）。

**3. 边属性访问** — `MATCH ()-[r]->() RETURN r.num` 现在返回边属性值。修复 `edgesPayload` 中缺少 `props`、`edgeVarCols` 过滤掉含 `.` 的列、`__edgeProps` 传播到 `_formatResultRow`。

**4. 标签谓词** — `MATCH (n) RETURN (n:Foo)` 现在正确返回 boolean。修复：在 `_evalAtom` 的括号剥离前先检测标签谓词模式 `^\((\w*)\s*:\s*(\w+)\)$`；并在 `_evalAtom` 中添加独立 `variable:Label` 模式处理（当 `_evalComparison` 先剥离括号后传递 `n:Foo`）。

**5. UnknownFunction** — `MATCH (a) RETURN foo(a)` 现在抛出 `SyntaxError: UnknownFunction`。新增 `_validateUnknownFunctions` 检测 RETURN 列中的已知函数。

**6. RETURN * 空列** — `RETURN *` 不再被 fallback 代码误认为列 `"*"`，保持空列。

### 修复内容（提交 976010d7）

**1. `_fixScanLabel` regex 修复** — `:A` 在 `:A:B` 中不被识别为 label（lookahead 只接受 `)` / 空格 / 行尾，不接受 `:`）。修复：lookahead 加上 `:`。

**2. 多标签检测修复** — 当 `_fixScanLabel` 清空了 `scanLabel`，多标签检测代码不运行。新增 fallback 路径：从 query 文本推测多标签并恢复 scanLabel + labelExpr。

**3. 提取 MATCH 变量的 regex** — `/(\w+)\s*(?::|\))/g` 不匹配内联属性模式 `(n {...})`。修复：在 lookahead 中增加了 `{`。

**4. 笛卡尔积支持 `MATCH (n), (m)`** — 单变量无边 MATCH 处重构为多变量通用版本，支持 `>= 2` 变量通过递归生成笛卡尔积。

**5. scanLabel 过滤 edge walk** — `_walkMultiSteps` 遍历时从所有节点索引 0 开始，不按标签过滤。新增 `plan.scanLabel` 过滤起始节点。

**6. 自环遍历修复** — 移除 `neighborIdx !== fidx` 限制（阻止自环匹配），移除 undirected fallback 中的自环排除。

**7. OR 类型边标签支持** — `edgeLabel` 按 `|` 分割检查（`:KNOWS|HATES`）。
