## 修复详情
  
### 修复详情

1. **middleWith 行投影保留原始变量** (query-engine.ts:1856):
   - `newRow = {}` → `newRow = { ...row }` (从原始行开始，保留 i, j 等 UNWIND 变量)
   - 这样 WHERE 过滤条件 `i <> j` 能正确访问 UNWIND 变量

2. **middleWith WHERE 使用完整上下文** (query-engine.ts:1881):
   - `_evaluateExpression(whereExpr, row)` → `_evaluateExpression(whereExpr, fullCtx)` where `fullCtx = { ...varCtx, ...row }`
   - 确保 WHERE 条件能访问 varCtx 和 row 中的所有变量

3. **Step3 WHERE 过滤支持多级 WITH** (query-engine.ts:1957):
   - 将 `if (!plan.hasMatch)` 改为 `if (!plan.hasMatch || (plan.hasMatch && plan.unwind))`
   - 提取最后一个 WITH 的 WHERE 子句（而非全局第一个）
   - 支持 `pipeline` 中的 WHERE result 过滤
