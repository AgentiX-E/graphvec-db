# 2026-06-17 TCK 修复日志

## 修复 Pattern + Quantifier TCK 场景

### 修改文件
`src/query/query-engine.ts`

### 修复内容

1. **`_validateUndefinedVariables`**
   - 从 WHERE 主体中剥离 `:Label` 类型符号（避免将 REL1、Label 误判为变量引用）
   - 剥离 `[...]` 中的变量名（如 [r], [:REL1*] 中的 r 是局部绑定）
   - 剥离箭头符号 `<-`, `->`, `--`
   - 从 `plan.returnColumns` 提取标识符（允许模式引入的变量在 RETURN 中使用）
   - 从 WHERE 子句的 `(变量)` 模式中提取标识符

2. **`_validatePatternPosition`** (新增)
   - 检测 RETURN、WITH、SET 子句中顶层的关系模式语法
   - 抛出 `SyntaxError: UnexpectedSyntax`

3. **`_validateWhereSelfPattern`** (新增)
   - 检测 `WHERE (n)` 自模式（无关系部分）
   - 抛出 `SyntaxError: InvalidArgumentType`

4. **`__crossVarRows` 源绑定修复**
   - 使用 `allNodes[i]`（当前迭代索引）替代 `allNodes.find(n => n._label === plan.scanLabel)`
   - 因为 `plan.scanLabel` 已被 `_fixScanLabel` 清空为 null

5. **`_formatResultRow` expr fallback**
   - 当 `aliasMap` 未定义时，如果 `rc` 是简单变量名且存在于 `varCtx` 或 `row`，直接用 `rc` 作为表达式

6. **`hasPatternPredicate` 检测**
   - 添加模式谓词触发条件，包括 `(n)--(m)` 无括号边模式
