### 关键技术决策
1. **关系 SET**：当所有 SET target 是 edgeVariable 时，操作 `__crossVarRows[alias]` 而非节点。
2. **CREATE 边属性**：`CREATE ()-[:R {num:1}]->()` 的 props 存入 `__edges[].props`。
3. **CREATE+SET 链**：SET 执行移到 CREATE 节点创建后（line 1371+），独立于 returnColumns。
4. **DML 聚合时序**：DML + aggregate 时删 `planForGe.aggregate`，让 QE 先做副作用再聚合（否则 GE 折叠成 sum=旧值）。
5. **聚合 field 前缀**：`_formatResultRow` 把 `n.num` 扁平化成 `num`，聚合 sum/avg/min/max 需去前缀读列；关系变量 `r.num` 需从 `__crossVarRows` 读。
6. **SET 持久化**：allNodes 是 shallow clone，finally 里 `plan.type==='SET'/'REMOVE'/'MATCH_MODIFY'` 时把 `allNodes[i]` 属性覆盖回 `nodes[i]`（`delete dst[k]` + `Object.assign`）。
7. **浮点除法**：`/` 结果整数值包装 `{__float:q}` 以渲染 `1.0`。
8. **InvalidPropertyType**：`_isInvalidPropertyValue` 检测 map 或 list 含 map。
