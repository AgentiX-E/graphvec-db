 *
 * 在 EventBus（ZeroMQ PUB/SUB）之上增加至少送达一次、去重和离线追赶。
 *
 * 架构：
 *   GraphEngine.emit(event)
 *       │
 *       ▼
 *   EventStream.emit(msg)                ← 用户入口
 *       ├── StreamWal.append(msg)
 *       └── eventBus.emit(event)         ← 原始 EventBus PUB（fire-and-forget）
 *
 *   eventBus.subSocket.receive()
 *       │

 *       │              → 回调
